Free tokens for vibe coders

Your agent stops when the tokens run out. These three free paths keep it going — all on your phone, no PC, no payment.

The token problem

Vibe coding burns tokens fast: every prompt, every fix, every "try again" costs tokens, and the free quota on a single provider runs out in the middle of a project. The fix is not one bigger free tier — it is stacking free tiers: a router that pools many providers, gateways that need no key at all, and apps that run the agent on your phone. All three paths below are free and open-source where stated, and every tool is listed in the Live API Hub directory with its free tier verified.

  1. Path 1 — OpenCode in Termux + FreeLLMAPI: the biggest free pool, some setup.
  2. Path 2 — No-key free gateways: working in minutes, smaller limits.
  3. Path 3 — Free automation on Android: which app to use for what.

Path 1 — OpenCode in Termux + FreeLLMAPI

Run the OpenCode coding agent on your phone in Termux, pointed at FreeLLMAPI — a self-hosted router that aggregates free LLM providers behind one OpenAI-compatible API. OpenCode itself already has 13 free models built in (GLM-5.3-Flash Free, DeepSeek V4.1 Flash Free), so it works free out of the box; the router adds the pooled capacity of many more providers.

Step 1 — Install OpenCode for Termux

Do not use plain npm i -g opencode-ai — it does not work reliably in Termux. Use the native aarch64 build, OpenCode for Termux (free, open-source, MIT): a standalone zip, pacman or .deb from its releases page. It needs ripgrep:

pkg install ripgrep

Step 2 — Install FreeLLMAPI

Follow the project's official Termux guide. It needs Node.js 22.13+ (Termux ships Node 26, so the version requirement is met), Android 7+, about 1 GB of storage, and Termux from F-Droid. The guide's install steps:

pkg install -y nodejs-lts git
git clone https://github.com/tashfeenahmed/freellmapi
cd freellmapi
npm install
npm run dev

The dashboard runs at localhost:5173 and the API at localhost:3001/v1.

Experimental. FreeLLMAPI's own Termux guide is marked experimental and community-supported by the project, and we have not tested the install ourselves. If it breaks, the project's repo is the place to ask.

Step 3 — Point OpenCode at the router

In OpenCode's provider settings, point it at the router's local API endpoint (http://localhost:3001/v1) and use the router's unified key. Then add your own free provider keys in the FreeLLMAPI dashboard — the router pools the free tiers you sign up for.

The honest numbers

FreeLLMAPI's own README claims 10.1 billion tokens per month of listed free-tier capacity, across 87 providers and 1,313 endpoints. That is the project's own figure: it counts the listed free-tier capacity of every provider, including rate-limit estimates, and it assumes you set up accounts with all of them. It is not a guaranteed allowance. The live catalog costs $19/year or $49 once; the free version gets a monthly snapshot. The project states it is for personal experimentation only, not production.

Path 2 — No-key free gateways

No install, no server: these gateways are OpenAI-compatible, so any agent that takes a base URL and a key can use them. Pick one, or rotate between them when one limit runs out. Limits are from each provider's own docs, as listed in the Hub's FreeLLM API category.

GatewayFree limitKey needed?
Kilo Code Gateway 200 requests/hour per IP (anonymous, kilo-auto/free router) No — no key, no signup
LLM7.io 100,000 tokens per 24 hours; 60 RPM / 250 req/hour Free token
UnoRouter ~1 request/min per model per account, no daily cap; 150+ free models incl. DeepSeek V4.1 Flash + GLM 5.3 Flash Free API key
OrcaRouter 10 RPM / 50 requests per day free; DeepSeek V4.1 Flash Free + GLM 5.3 Flash Free, no card Free API key

Privacy note. Kilo's Auto Free router may send requests to providers that log prompts and outputs — do not send sensitive data through it. LLM7.io states its free quota may shrink without notice, so treat these limits as "today's", not permanent.

Path 3 — Free automation on Android

Which app depends on what you want the agent to do. All five are free and open-source, listed in the Hub's Agent For Android category.

  • AiCode — for coding. A full AI coding agent on Android: built-in Alpine Linux container, terminal, code editor and Git, with MCP support, sub-agents and skills. Model-agnostic — bring your own key; works with OpenAI/Anthropic/Gemini-compatible endpoints, including free gateways.
  • RikkaHub — for phone automation + coding. Native Android LLM client with a proot Linux agent workspace and Phone Use — the AI operates your phone. MCP, Skills and web search built in. Multi-provider: custom API/URL/models for any OpenAI/Google/Anthropic-compatible endpoint, including free gateways.
  • DSH-Android — for operating the phone. DeepSeek Harness as a single APK: operates apps, files and system settings, with automation triggers and a built-in Linux environment. No root, no Termux. Unofficial community port, no DeepSeek affiliation. Play Protect may flag the APK — verify the SHA-256.
  • OpenClaw App — for a one-tap agent gateway. The OpenClaw AI gateway as a standalone Android app: Flutter UI with built-in terminal and web dashboard, one-tap setup, no root (Ubuntu via proot). Multi-model via the gateway — works with free gateways. Android 10+.
  • PocketPal AI — for private, offline chat. Chat with GGUF models fully offline, with voice, tools and Hugging Face model downloads. Honest note: it is local-only — it runs small models on-device and has no cloud models or gateway path, so it is not a coding-agent backend. Optional PocketPal Plus purchase in store builds; included free in the GitHub APK.
